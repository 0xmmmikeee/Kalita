# Версии и откат

Автопилот на VPS разворачивает ветку `main` каждую минуту (код; `data/` и `state/` не трогаются).
Каждая выпущенная версия закреплена веткой `release/vX.Y.Z`.

- Текущая: `release/v0.8.5` (кнопка копирования адреса рядом с каждым адресом во всех таблицах и в карточке; тост «Copied», 12 языков).
- Предыдущая: `release/v0.8.4` (таблицы: однострочные заголовки в компактном режиме, короткие даты, причина по-английски с подсказкой, приглушённые «—», табличные цифры).
- Предыдущая: `release/v0.8.3` (стрелки сортировки не отрываются от последнего слова заголовка).
- Предыдущая: `release/v0.8.2` (скоринг читает signals.csv кусками — пик памяти ~6 ГБ → ~2.5 ГБ, лечит OOM-kill daily 29.09; на VPS добавлен swap 6 ГБ).
- Предыдущая: `release/v0.8.1` (кэш gzip-ответа кандидатов: 0,7 с → мс; cache-control для i18n.js/favicon; таймер самопроверки доступности каждые 2 мин с авто-рестартом Caddy/панели).
- Предыдущая: `release/v0.8.0` (панель: побайтовый индекс сигналов без утечки SlicedString — лечит цикл heap OOM; плоские строки в CSV; кэш кандидатов; рестарт только при изменении `src/`; страница «перезапуск» вместо пустого 502).
  Ранее: v0.7.2 (кап кандидатов 5000), v0.7.1 (typed-array индекс), v0.6.5, v0.5.1, v0.2.0, v0.1.0.

Откат на предыдущую (через минуту на сервере):
```bash
git checkout main && git revert -m 1 --no-edit $(git log --merges -1 --format=%H) && git push origin main
```
или жёстко, к конкретной версии: `git push --force origin release/v0.1.0:main` (история main перепишется — только если revert не подходит).
Вернуть новую: `git push --force origin release/v0.2.0:main` или revert реверта.
