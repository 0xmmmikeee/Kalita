List registry

Every daily snapshot of a Kalita list is published here as a Merkle root of its members with the size and the wallets added and removed. The same root is committed to KalitaRegistry on Robinhood Chain, so a list can never be rewritten in hindsight. Anyone can verify that a wallet was on the list on a given day — below, in your browser.

Verify a wallet

Pick a snapshot, paste an address. The proof is fetched from the snapshot file and checked against the root here, in your browser — nothing is sent to us.

How the root is built

leaf = keccak256(0x00 ‖ address) · node = keccak256(0x01 ‖ min(a,b) ‖ max(a,b)) · odd leaf carried up unchanged. The same function is used by contracts/KalitaRegistry.sol (verifyMember) and by src/registry_snapshot.py; the shared test vector is in the repository.
